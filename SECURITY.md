# Politica di Sicurezza

## Segnalazione di una vulnerabilità

Questo progetto è un'applicazione web statica lato client (un singolo file HTML/JS/CSS) che non raccoglie dati degli utenti, non utilizza database e non ha un server backend. 

Di conseguenza, il rischio di vulnerabilità di sicurezza è praticamente nullo. 

Tuttavia, se dovessi notare un comportamento anomalo o un potenziale problema, ti invito a segnalarlo aprendo una "Issue" nella repository.
