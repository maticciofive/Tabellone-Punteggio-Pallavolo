# 🏐 Tabellone Pallavolo (Volleyball Scoreboard)

Un'applicazione web leggera, responsive e gratuita per tenere il punteggio delle partite di pallavolo. Progettata per essere utilizzata su tablet (iPad), smartphone e desktop, senza necessità di installazione o connessione internet una volta caricata.

🔗 **Prova l'app live qui:** [https://maticciofive.github.io/tabellone/](https://maticciofive.github.io/tabellone/)

## ✨ Funzionalità Principali

- **Configurazione Completa:** Personalizza nomi delle squadre, colori, numero di set per vincere, punti per set (normale e tie-break) e regole di scarto.
- **Regole Ufficiali:** Gestione automatica dello scarto di 2 punti, set decisivo (tie-break) e limite massimo di punti (cap).
- **Controlli Touch Intuitivi:** 
  - 👆 **Tap (Tocco):** Aggiunge 1 punto.
  - 👆⏱️ **Long Press (Pressione prolungata):** Toglie 1 punto (perfetto per correggere errori dell'arbitro).
- **Interfaccia Responsive:** Si adatta automaticamente all'orientamento orizzontale (landscape) o verticale (portrait).
- **Storico e Stato:** Visualizza i set vinti, il set corrente e lo storico completo dei punteggi.
- **Strumenti di Gioco:** Pulsanti per "Cambia Campo", "Annulla ultima azione" e "Nuova Partita".
- **Dark Mode:** Design scuro per non affaticare la vista in palestra e risparmiare batteria.

## 📱 Come si usa (Ottimizzato per iPad)

L'app è progettata per funzionare come una **Progressive Web App (PWA)** senza bisogno di store.

1. Apri il link [https://maticciofive.github.io/tabellone/](https://maticciofive.github.io/tabellone/) nel browser **Safari** del tuo iPad.
2. Tocca l'icona **Condividi** (il quadrato con la freccia verso l'alto in basso o in alto a destra).
3. Scorri il menu e seleziona **"Aggiungi alla schermata Home"**.
4. Ora avrai un'icona dedicata. Aprendola, l'app partirà a **tutto schermo**, nascondendo la barra degli indirizzi di Safari!

> 💡 **Consiglio Pro:** Vai nelle *Impostazioni* dell'iPad > *Schermo e luminosità* > *Blocco automatico* e impostalo su **Mai**, per evitare che lo schermo si spenga durante la partita.

## 🛠️ Tecnologie Utilizzate

- **HTML5** per la struttura.
- **CSS3** (Flexbox, Grid, Variabili CSS) per il design responsive e la Dark Mode.
- **JavaScript (Vanilla)** per la logica di gioco. 
- *Nessun framework, nessuna libreria esterna, nessun backend.* Tutto il codice è contenuto in un **singolo file `index.html`**, rendendolo facilissimo da distribuire.
